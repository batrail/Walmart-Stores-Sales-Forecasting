# Cleaned Data

This directory stores processed datasets generated by running [`scripts/data-cleaning.R`](../../scripts/data-cleaning.R).

---

## Output Files
- **`features_clean.rds`**: Cleaned features dataset (zero-filled markdowns, trend-imputed CPI and Unemployment).
- **`train_merged_clean.rds`**: Full merged training dataset (`train.csv`, `features_clean`, `stores.csv`) with extracted calendar features (`Year`, `Month`, `Week`).
- **`test_merged_clean.rds`**: Full merged test dataset prepared for out-of-sample forecasting.

---

## Summary of Cleaning Steps
1. **Date Formatting**: Standardized dates to Date objects using `lubridate::ymd()`.
2. **Negative Sales**: Preserved as valid retail returns/refunds (<0.3% of rows) to avoid overstocking biases.
3. **Markdowns (`MarkDown1`–`MarkDown5`)**: Missing values prior to November 2011 replaced with `0`; negative accounting adjustments clamped to `0`.
4. **CPI & Unemployment**: Missing 2013 values imputed per store using linear trend regression on time index (`lm`).
5. **Merging**: Merged `train` and `test` with cleaned features and static store metadata, extracting `Year`, `Month`, and `Week`.

---

## How to Generate
1. In RStudio, set your working directory to the repository root folder:  
   **Session** -> **Set Working Directory** -> **Choose Directory...**
2. Execute the cleaning script:
   ```r
   source("scripts/data-cleaning.R")
   ```
