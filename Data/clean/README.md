# Cleaned Data

This directory stores processed datasets generated by running [`scripts/data-cleaning.R`](../../scripts/data-cleaning.R).

---

## Output Files
- **`features_clean.rds`**: Cleaned features dataset with markdown reporting indicators (`reported_markdown_count`, `has_any_markdown`), zero-filled and non-negative clamped markdowns, and store-level linear trend-imputed `CPI` and `Unemployment`.
- **`train_merged_clean.rds`**: Merged training dataset (`train.csv`, `features_clean`, `stores.csv`) with calendar features (`Year`, `Month`, `Week`) and chronological validation `split`.
- **`test_merged_clean.rds`**: Merged test dataset (`test.csv`, `features_clean`, `stores.csv`) with calendar features (`Year`, `Month`, `Week`) prepared for forecasting.

---

## Summary of Cleaning Steps & Added Columns
1. **Date Formatting**: Standardized `Date` columns to `Date` objects using `lubridate::ymd()`.
2. **Markdown Indicators & Imputation (`MarkDown1`–`MarkDown5`)**:
   - Computed `reported_markdown_count` (count of non-missing `MarkDown1`–`MarkDown5` values prior to imputation).
   - Computed `has_any_markdown` as a logical (`TRUE`/`FALSE`) flag (`reported_markdown_count > 0`) prior to imputation.
   - Replaced missing markdown values with `0` (assumed 0 lift) and clamped negative values to `0`.
3. **CPI & Unemployment Imputation**: Imputed missing values per `Store` using linear trend regression on numeric date (`lm(CPI ~ time_num)` and `lm(Unemployment ~ time_num)`).
4. **Negative Sales**: Preserved negative `Weekly_Sales` values (less than 0.3% of rows) as valid retail returns/refunds to avoid overstocking bias.
5. **Merging, Calendar Features & Validation Split**:
   - Joined `train` and `test` with `features_clean` (by `Store`, `Date`, `IsHoliday`) and `stores` (by `Store`).
   - Extracted `Year`, `Month`, and `Week`.
   - Added `split` to `train_merged_clean.rds` using `validation_cutoff <- ymd("2012-05-04")` (`"train"` for `Date < validation_cutoff`, `"valid"` for `Date >= validation_cutoff`, holding out roughly 6 months / 26 weeks).

## How to Generate
1. In RStudio, set your working directory to the repository root folder:  
   **Session** -> **Set Working Directory** -> **Choose Directory...**
2. Execute the cleaning script:
   ```r
   source("scripts/data-cleaning.R")
   ```
